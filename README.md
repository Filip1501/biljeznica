# Bilježnica

Aplikacija naredbenog retka za vođenje popisa zadataka (Node.js, ES moduli).

- `glavni.js` – čita argumente i izvršava naredbe
- `pohrana.js` – učitavanje i spremanje zadataka u `zadaci.json`

## Korištenje

    npm start -- dodaj "Napisati izvještaj"
    npm start -- popis
    npm start -- gotovo 1
